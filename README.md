# Rustamjon & Madinabonu — Qiz bazmi taklifnomasi

25-oktabr 2026, «Asr» to'yxonasi, Toshkent.

Bitta `index.html` faylidan iborat onlayn taklifnoma:
- gullar bilan bezatilgan darvoza intro, muhr sinishi, eshik ochilishi va gul barglari
- kalendar, bazmgacha qolgan vaqt taymeri, xarita (Yandex, Google Maps)
- mehmonlar bazmdan suratlarni yuklaydi, ularni faqat to'y egalari PIN orqali ko'radi
- "Kelasizmi?" anketasi

## Saytni yoqish (GitHub Pages)
Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
Bir daqiqadan keyin sayt `https://<foydalanuvchi>.github.io/<repo>/` manzilida ochiladi.

## Sozlash
Sana, vaqt va PIN `index.html` ichidagi `CONFIG` blokida. Mehmonlar suratlarini haqiqatda yuklashi uchun Supabase ulash kerak: `SETUP.md` ga qarang.
